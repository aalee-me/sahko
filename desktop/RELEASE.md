Sähkö macOS companion for macOS 13 or later, Apple Silicon and Intel.

Download Sahko-macOS.zip, unzip it and move Sahko.app to Applications. This is an ad-hoc signed demo, not Apple-notarized. macOS may require opening it from Finder and confirming it in System Settings → Privacy & Security → Open Anyway. Never disable Gatekeeper globally.

Launch Sähkö and use the ö menu-bar icon. The floating panel can stay above other apps and follow Spaces. Open Settings to explicitly enable local monitoring, customize app buckets, permit optional Safari/Chrome/Arc domain context or Spotify playback, and pair a phone over the internet.

Monitoring starts off. No screenshots, screen recording, window titles, keystrokes, raw app names or browser URLs are uploaded. Only processed state, an optional approved broad activity label, timer and room display information can sync. YouTube audio uses an explicit manual exemption; it is not automatically detected across every browser. Quiet reading has a longer, bounded idle check-in.

Internet phone pairing requires the Sähkö companion API deployment. The website stays on GitHub Pages; the API is a separate host. A pairing code is single-use and expires after ten minutes. Stop pairing revokes the phone token.

0.4: the compact panel remains visible above other apps and can show automatically on app switches during an active session. Pin and auto-show preferences persist. Local settings can classify the current app directly and optionally detect Apple Music as well as Spotify playback. Monitoring remains opt-in; browser domains and input idle time stay local.
